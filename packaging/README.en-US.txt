RoboCopyUI 1.7.3 — Windows 11 x64

Installs for the current user in LocalAppData\Programs\RoboCopyUI. Includes the .NET 10 desktop runtime; no SDK is required. Search for RoboCopyUI in Start to open settings.

Use File Explorer's Ctrl+C / Ctrl+X, then press Ctrl+Alt+V in the destination file list to paste with RoboCopyUI. Press Ctrl+Alt+Shift+V for a full-preservation paste. /ZB uses restartable mode and tries backup mode on access denial. /COPYALL requests all file metadata, including permissions, ownership and audit information.

Ctrl+Alt+D requests permanent deletion. Confirmation, execution and results share one window. Cancel is the default; deleted items do not go to the Recycle Bin. Change or clear each shortcut in settings, or pause shortcuts from the tray. Shortcuts apply only in the Explorer file list. Ordinary system copy, cut and Delete retain their behavior.

A sound plays after a successful copy or move, never for failure, cancellation or deletion. Full-preservation failures stop with an explanation. Choose normal copy for this task, retaining the source, or request a one-time administrator retry. Moves clean up sources only after copying and verification. Destination-only files are retained. Defaults: 3 retries, 5 seconds between retries.

Choose Simplified Chinese or English in settings. Closing settings keeps the tray running. The tray offers tasks, shortcut pause, automatic startup and exit. Automatic startup runs only in the tray without opening settings.

Exit from the tray and wait for tasks to stop before upgrading, repairing or uninstalling.

Uninstall retains settings and task logs by default. Optional cleanup removes only recognized application data; unknown files remain. Copy sources and destinations are never uninstall cleanup targets.
